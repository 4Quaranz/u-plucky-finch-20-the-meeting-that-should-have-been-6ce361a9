A program that writes one joke, a single line of at most 200 characters, about a meeting that should have been an email:

> This meeting could have been an email. Instead, twelve people nodded at a slide nobody read for an hour, then agreed to meet again.

The line is 131 characters: an hour of nodding, zero reading, zero decisions — and the only outcome is another meeting.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.txt` — exactly the line above, no trailing newline, deterministic across runs.
